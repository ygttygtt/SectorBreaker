# 现有文档复用说明

## 是否需要把原 `docs/` 全部导入面试知识库

不建议。原项目文档同时包含历史版本、开发交接、旧架构复盘和面向 Agent 的操作规则，直接全量导入容易让面试助手召回已经退休的 V1/V2 Workflow、Talent Demand 或过期成熟度描述。

本 `知识库` 目录已经把当前 V3 相关内容重新整理为面试语料，可以直接整目录导入。

## 不建议直接导入的内容

- `docs/superpowers/plans/`：包含大量历史计划和过渡设计。
- 旧 V1/V1.6/V2 Spec：可能与当前 V3 冲突。
- 早期 Talent Demand/Boss Job Source 文档：已退休。
- `docs/23-agent-kernel-interview-guide.md`：有大量高质量 Agent 解释，但其中“当前生产核心是单 Master、Multi-Agent 不是生产核心”等段落已经落后于当前 V3 Specialist 实现。本知识库已吸收并更新其有效内容。

## 推荐导入方式

第一轮只导入 `知识库/`，验证面试工具能否正确回答：

1. 为什么不是固定 Workflow？
2. RAG 如何增量索引和 RRF？
3. Specialist 为什么不能 Apply？
4. Checkpoint 如何恢复？
5. ChangeSet 如何防覆盖？
6. 已上线与 Local-first 是否冲突？
7. 当前有哪些技术边界？

如果回答细节不够，再补充上面列出的原始文档，而不是一次性导入整个仓库。
