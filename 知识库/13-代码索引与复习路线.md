# 代码索引与复习路线

## 第一优先级：Agent Kernel

### `backend/app/agent_kernel/pipeline.py`

重点：

- 生产入口 `run_v2_agent_kernel_pipeline`；
- 新建 State / Resume State；
- 上传资料内化；
- Maintenance Request 和 AutonomyPolicy；
- Active Artifact Memory；
- Artifact-first Checkpoint；
- Budget 恢复；
- Final Checkpoint 和 No Artifact Failure。

### `backend/app/agent_kernel/runtime.py`

重点：

- ReAct Loop；
- Finish Gate；
- Budget Check；
- Decision Heartbeat；
- Observation -> Reducer；
- Writer Failure/Partial Success；
- Waiting for Human；
- Consecutive Failure Stop；
- Trace Event。

### `backend/app/agent_kernel/models.py`

重点模型：AgentActionType、ToolCall、ToolSpec、KernelStateDelta、AgentDecision、KernelObservation、KernelLoopConfig、KernelRunResult。

### `backend/app/agent_kernel/policy.py`

重点：Context Build、Structured Completion、JSON Repair、Soft Runtime Guidance、Prompt 组合。

### `backend/app/agent_kernel/reducer.py`

重点：StateDelta 合并、Claim 去重/冲突/Supersede、Unknown Evidence Verified Claim 降级、Memory Governance。

## 第二优先级：State 和 Context

### `backend/app/agent_state/models.py`

重点：SectorBreakerState、MetaContext、KnowledgeSchema、KnowledgeClaim、SourceMemory、TaskMemory、ArtifactMemory、AutonomyPolicy、RunBudgetUsage。

### `backend/app/agent_state/context_pack.py`

重点：如何筛选上下文、排除噪声和压缩 Working Memory。

### `backend/app/agent_state/report_internalizer.py`

重点：上传报告如何转 Claim、Entity、Open Question，以及低信任处理。

## 第三优先级：Tools 和 Specialist

### `backend/app/agent_kernel/tools/`

- `search.py`：Query Variant、Source Policy、Provider Budget、正文抽取、Evidence 构建。
- `documents.py`：上传资料和项目记忆检索。
- `state.py`：Coverage、Reflection、Memory Governance。
- `artifacts.py`：主文档、解释卡、导航、Review、Revision。
- `knowledge_base.py`：Health/Backlog/ChangeSet。
- `specialists.py`：并发委派。
- `human.py`：等待人工。

### `backend/app/agent_kernel/specialists.py`

重点：四类 Role、Finding、Recommendation、Change Suggestion 和 Role Allowlist。

## 第四优先级：RAG

### `backend/app/rag/project_retriever.py`

重点：Lexical Candidates、Vector Candidates、RRF、Citation Provenance、Honest Degradation。

### `backend/app/rag/vector_index.py`

### `backend/app/providers/embeddings.py`

## 第五优先级：Evidence 和 Provider

### `backend/app/providers/interfaces.py`

### `backend/app/providers/multi_search.py`

重点：Concurrency、Failure Isolation、Canonical Dedup、Round-robin。

### `backend/app/providers/search_execution.py`

### `backend/app/providers/source_policy.py`

### `backend/app/providers/url_safety.py`

重点：Public URL 和 SSRF Gate。

## 第六优先级：知识控制面

### `backend/app/knowledge_base/vault.py`

重点：Safe Import、Snapshot Hash、Deterministic Audit、Stable Task Fingerprint。

### `backend/app/knowledge_base/changes.py`

重点：Propose/Approve/Apply/Rollback、Base Hash、Evidence Gate、Whole-journal Prevalidation。

### `backend/app/exporters/markdown.py`

重点：Active-only、Stale Export Cleanup、Front Matter、`.sectorbreaker` Bundle。

## 第七优先级：API 和持久化

### `backend/app/api/app.py`

重点：Run 创建、Maintenance Run、SSE、Snapshot、Resume、Recover、Chat/Follow-up、Config 和 Export。

### `backend/app/storage/sqlite.py`

重点：Artifact Supersession、Vector Blob、Run Lease、CAS Resume、Stale Reconcile、Checkpoint。

### `backend/app/storage/migrations/`

重点：24 个 Migration，特别是 Artifact Revision、Knowledge Management、Vector Index、Evidence Metadata、Source Preferences 和 Run Lease。

## 三天复习路线

### 第一天：讲清架构

1. 读 Pipeline、Runtime、Models；
2. 手画 Decide -> Tool -> Observation -> Reducer；
3. 能解释为什么 L1-L5 不是 Workflow；
4. 能说出所有 Finish/Failure/Waiting 条件。

### 第二天：讲清数据和安全

1. 读 State、RAG、Evidence；
2. 解释 RRF、Content Hash 和 Lexical Degraded；
3. 读 ChangeSet 和 Vault；
4. 手画 Revision/Conflict/Rollback；
5. 解释 Source Policy、预算和 SSRF。

### 第三天：准备追问

1. 复述真实验收；
2. 准备一个失败复盘：固定 Workflow 泄漏；
3. 准备一个数据一致性案例：Artifact-first Checkpoint；
4. 准备一个安全案例：Evidence Fail-closed；
5. 准备当前不足和下一步，不夸大。
