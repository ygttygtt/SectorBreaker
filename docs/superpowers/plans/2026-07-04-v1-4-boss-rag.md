# V1.4 Boss Source And Project RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a real enterprise talent-demand source path through Boss-compatible job collection and upgrade project Q&A into retrieval-augmented answers without breaking the existing personal domain-knowledge flow.

**Architecture:** Add a `JobSourceProvider` boundary and a Boss CLI adapter that produces structured job postings, then feed those postings into the existing talent-demand Evidence Ledger path. Add a project-local retriever that searches evidence, uploaded documents, and generated artifacts, and have `/chat` answer through the configured LLM with citations when possible.

**Tech Stack:** FastAPI, Pydantic, SQLite FTS, React + TypeScript, local CLI provider adapter, existing OpenAI-compatible LLM provider.
