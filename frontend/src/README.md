# Frontend Source Skeleton

Planned module boundaries:

- `api/`: typed API client.
- `components/`: reusable UI components.
- `features/projects/`: project creation and project detail.
- `features/runs/`: run cockpit and stage review.
- `features/artifacts/`: artifact browser and export UI.
- `features/chat/`: project-local Q&A.

Prefer typed API contracts and focused components over large pages with embedded business logic.
