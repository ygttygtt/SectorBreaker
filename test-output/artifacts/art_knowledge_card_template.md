# 大健康保健品行业知识卡片模板

## 示例卡片：益生菌保健品

### 节点名称
益生菌保健品

### 一句话定义
含有特定益生菌株、旨在调节肠道菌群平衡、增强消化或免疫功能的保健食品。

### 它解决什么问题
解决因饮食不规律、压力、抗生素使用等导致的肠道菌群失衡问题，如腹胀、便秘、免疫力下降等。

### 它和哪些节点相关
- [[肠道健康]]
- [[免疫力提升]]
- [[微生态制剂]]
- [[功能性食品]]
- [[膳食补充剂]]

### 关键事实
- 中国是全球益生菌保健品增长最快的市场之一，年均增长率超过15%。
- 国家市场监管总局对益生菌菌株的添加和标注有严格规定。
- 消费者认知从“助消化”扩展到“免疫调节”和“情绪管理”。

### 关键指标
- 市场规模（亿元）
- 主要菌株（如乳杆菌、双歧杆菌）存活率
- 消费者复购率
- 线上渠道销售占比

### 代表玩家
- 汤臣倍健
- 合生元（Biostime）
- 养生堂
- Life-Space（属澳佳宝）

### 典型案例
汤臣倍健“Life-Space”益生菌系列，通过跨境电商引入中国市场后，针对中国消费者体质进行配方优化，并利用KOL（关键意见领袖）营销，快速占领线上市场。

### 常见误区
- 所有益生菌都一样：不同菌株功效差异大，需明确标注菌株号。
- 活菌数越多越好：活菌到达肠道的有效数量更重要，而非初始添加量。
- 益生菌可以替代药物：它属于保健食品，不能治疗疾病。

### 待验证问题
- 益生菌对情绪调节（脑肠轴）的实际效果需要更多临床证据。
- 长期服用特定益生菌是否会导致菌群依赖或失衡？

### 资料来源
1. 中国保健协会《2023益生菌行业白皮书》
2. 国家市场监管总局保健食品备案与注册信息
3. 天猫、京东平台益生菌品类销售数据报告

## 卡片结构说明

| 字段 | 说明 |
|------|------|
| 节点名称 | 知识图谱中的核心实体或概念 |
| 一句话定义 | 用一句话清晰定义该节点 |
| 它解决什么问题 | 描述该节点在行业中的核心价值或作用 |
| 它和哪些节点相关 | 列出相关概念、技术、市场环节，用Obsidian双链格式 [[]] 表示 |
| 关键事实 | 3-5条经过验证的行业事实或数据点 |
| 关键指标 | 衡量该节点发展状况的关键数据指标 |
| 代表玩家 | 涉及该节点的主要公司或品牌 |
| 典型案例 | 具体的商业案例或应用场景 |
| 常见误区 | 行业普遍存在的错误认知或理解 |
| 待验证问题 | 需要进一步研究或存在争议的问题 |
| 资料来源 | 数据、观点的权威出处 |

## 如何使用这张模板

1. **创建新卡片**：复制整个Markdown内容到Obsidian中，替换所有占位字段为新节点的具体信息。
2. **填写节点名称**：作为卡片标题（如“[[辅酶Q10]]”）。
3. **完善各字段**：根据研究，填充定义、问题、关联节点等。确保“相关节点”使用双链 `[[]]` 以建立知识网络。
4. **添加frontmatter**：在卡片顶部填写YAML格式的frontmatter，用于标签化、别名管理和关联图谱。
5. **维护与更新**：随着研究深入，更新“关键事实”、“待验证问题”等字段，并链接到新产生的相关卡片。
6. **知识网络构建**：通过“相关节点”和Obsidian的链接功能，逐步构建行业知识图谱，发现隐藏关联。
